==============================================================================
  AiDerm Cliniq — Local Development Setup Guide
  Platform : Windows 11
  Shell    : Any terminal (PowerShell, CMD, Git Bash, or Anaconda Prompt)
==============================================================================

WHAT YOU NEED
-------------
  1. Docker Desktop      — runs PostgreSQL + Redis containers
  2. Anaconda / Python   — runs the FastAPI server and Celery worker
  3. ngrok               — exposes your local server to the internet (for Flutter)
  4. Git                 — to clone the repo
  5. GCS credentials     — credentials/service-account.json (from Google Cloud)

==============================================================================
  STEP 1 — Clone & Install Dependencies
==============================================================================

  Open a terminal and run:

    cd "d:/@White Mastery Systems/Derm AI"

    # Activate your conda environment
    conda activate aiderm

    # Install all Python packages
    cd ai_derm_cliniq_server
    pip install -r requirements.txt

  That's it. No other install needed.


==============================================================================
  STEP 2 — Start PostgreSQL and Redis  (Docker Desktop)
==============================================================================

  Make sure Docker Desktop is open and running first.

  Run these two commands — each starts one container:

  ── PostgreSQL ──────────────────────────────────────────────────────────────

    docker run -d --name aiderm-postgres -e POSTGRES_USER=postgres -e POSTGRES_PASSWORD=postgres -e POSTGRES_DB=aiderm_cliniq -e POSTGRES_HOST_AUTH_METHOD=trust -p 5455:5432 postgres:16-alpine

  ── Redis ───────────────────────────────────────────────────────────────────

    docker run -d --name aiderm-redis -p 6379:6379 redis:7-alpine

  ── Verify they are running ─────────────────────────────────────────────────

    docker ps

    You should see both containers listed with status "Up".


  NOTE: Next time you start your PC, just run:

    docker start aiderm-postgres aiderm-redis


==============================================================================
  STEP 3 — Configure the .env File
==============================================================================

  Open:  ai_derm_cliniq_server/.env

  Make sure these values are set (they should already be correct):

    APP_ENV=development
    DATABASE_URL=postgresql+asyncpg://postgres:postgres@127.0.0.1:5455/aiderm_cliniq
    REDIS_URL=redis://localhost:6379/0
    GOOGLE_APPLICATION_CREDENTIALS=D:\@White Mastery Systems\Derm AI\ai_derm_cliniq_server\credentials\service-account.json
    GCS_BUCKET_NAME=aiderm-cliniq-storage
    GEMINI_API_KEY=<your key>

  APP_ENV=development is important — it enables /docs (Swagger UI).

==============================================================================
  STEP 5 — Start the FastAPI Server
==============================================================================

  Open a NEW terminal window and run:

    cd "d:/@White Mastery Systems/Derm AI/ai_derm_cliniq_server"
    conda activate aiderm

    "D:/Anaconda/envs/aiderm/python.exe" -m uvicorn src.main:app --host 0.0.0.0 --port 8880 --reload

  You should see:

    INFO:     Uvicorn running on http://0.0.0.0:8880 (Press CTRL+C to quit)
    INFO:     Application startup complete.

  Test it:

    curl http://127.0.0.1:8880/health

    Expected: {"status":"healthy","database":"ok","redis":"ok"}

  Swagger UI (API docs):

    Open in browser: http://127.0.0.1:8880/docs


==============================================================================
  STEP 6 — Start the Celery Worker  (AI Tasks)
==============================================================================

  Open a NEW terminal window and run:

    cd "d:/@White Mastery Systems/Derm AI/ai_derm_cliniq_server"
    conda activate aiderm

    "D:/Anaconda/envs/aiderm/python.exe" -m celery -A src.workers.celery_app worker --loglevel=info --pool=solo

  You should see:

    [tasks]
      . src.workers.tasks.analysis.analyse_images_task
      . src.workers.tasks.analysis.inspect_images_task
      . src.workers.tasks.questions.generate_questions_task
      . src.workers.tasks.questions.refine_analysis_task
      . src.workers.tasks.reports.generate_report_task
      . src.workers.tasks.red_flags.red_flag_check_task

    [config]
      .> app:          aiderm_cliniq
      .> transport:    redis://localhost:6379/1
      .> results:      redis://localhost:6379/2

    celery@<hostname> ready.

  NOTE: --pool=solo is required on Windows. Linux/Mac can use --pool=prefork.


==============================================================================
  STEP 7 — Expose to Internet with ngrok
==============================================================================

  This gives Flutter a public HTTPS URL to reach your local server.

  ── Install ngrok ────────────────────────────────────────────────────────────

    Download from: https://ngrok.com/download
    Sign up (free) and copy your authtoken from the dashboard.

    Run once to authenticate:
      ngrok config add-authtoken <your-token>

  ── Start tunnel ─────────────────────────────────────────────────────────────

    Open a NEW terminal window and run:

      ngrok http 8880

    You will see output like:

      Forwarding  https://f234-27-5-220-6.ngrok-free.app -> http://localhost:8880

  ── Use the ngrok URL in Flutter ─────────────────────────────────────────────

    Replace your API base URL in Flutter with the ngrok HTTPS URL:

      const baseUrl = "https://f234-27-5-220-6.ngrok-free.app/api/v1";

  NOTE: The ngrok URL changes every time you restart ngrok (free plan).
        Paid plan gives you a fixed subdomain.

==============================================================================
  TROUBLESHOOTING
==============================================================================

  Problem: alembic upgrade head gives "password authentication failed"
  Fix    : Check DATABASE_URL uses 127.0.0.1 (not localhost) and port 5455

  Problem: /docs returns 404
  Fix    : Set APP_ENV=development in .env, then restart uvicorn

  Problem: Celery tasks not running / AI stuck on "processing"
  Fix    : Make sure the Celery worker terminal is open and shows "ready"

  Problem: "GCS not configured" error on image upload
  Fix    : Check GOOGLE_APPLICATION_CREDENTIALS path in .env is correct
           Make sure credentials/service-account.json exists

  Problem: Port 5455 already in use
  Fix    : Stop conflicting process or choose a different port
           docker run ... -p 5456:5432 ...  and update DATABASE_URL port

  Problem: ngrok URL keeps changing
  Fix    : Either keep ngrok running, or upgrade to ngrok paid plan for a
           static domain
