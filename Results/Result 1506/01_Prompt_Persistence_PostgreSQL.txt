TASK — PROMPT PERSISTENCE (PostgreSQL + Redis)
Tested On : 2026-06-15
Server    : http://localhost:8880
Feature   : Admin AI Prompt Management — PostgreSQL as source of truth

WHAT WAS TESTED
─────────────────────────────────────────────────────────────────────
Before this feature, prompt overrides were stored only in Redis.
Redis relies on periodic RDB snapshots — data can be lost between
snapshots if Redis restarts or Docker volumes are wiped.

Fix implemented:
  • New tables: prompt_overrides (current value), prompt_history (last 10)
  • PostgreSQL is source of truth — writes go there first
  • Redis is a fast-read cache — warmed from PostgreSQL on server startup
  • Overrides now survive any restart, Redis wipe, or Docker volume change
